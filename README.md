# EduLab — Цахим лаборатори, хиймэл оюунд суурилсан сургалтын платформ

> **Сурагч бүрд туршиж суралцах боломж, багш бүрд ухаалгаар ажиллах нөхцөлийг бүрдүүлнэ.**
>
> erxes-ийн plugin · Hacktoberfest Hack Day Ulaanbaatar × erxes Hub, 2026-10-24

Сурагчид физик, химийн туршилтыг лабораторигүйгээр **цахим лаборатори** дээр
хийж, хэмжилт болон дүгнэлтээ илгээдэг. **Gemma 4** дүгнэлтийг сурагчийн
бодит хэмжилттэй тулгаж шалгуур бүрээр урьдчилсан оноо санал болгоно. Багш
хянаад батална.

**Demo бичлэг:** [`docs/edulab-demo.mp4`](docs/edulab-demo.mp4)

---

## 1. Төслийн нэр, зорилго

**EduLab — Боловсролын тэгш хүртээмжийг технологиор дэмжих нь.**

Монгол Улсын боловсролын салбарт технологийн дэвшлийг үр ашигтай нэвтрүүлж,
сурагч бүрд чанартай боловсрол эзэмших тэгш боломжийг бүрдүүлэх нь төслийн
зорилго юм. EduLab нь цахим лаборатори болон хиймэл оюунд суурилсан
шийдлүүдээр дамжуулан:

- сургалтын чанарыг сайжруулах,
- багшийн ажлын ачааллыг бууруулах,
- сурагчдын бие даан суралцах чадварыг хөгжүүлэхэд чиглэнэ.

## 2. Шийдэж буй асуудал, зорилтот хэрэглэгч

### Асуудал

Монгол Улсын зарим сургуульд лабораторийн тоног төхөөрөмж, зориулалтын
орчин болон байгалийн ухааны багшийн хүрэлцээ хангалтгүй байдаг. Үүний
улмаас сурагчид онолын мэдлэгээ туршилт, дадлагаар бататгах боломж
хязгаарлагдаж, сургалтын чанар болон хүртээмжид ялгаа үүсдэг. Мөн багш нар
даалгавар шалгах, алдааг тодорхойлох, үнэлгээ өгөх зэрэг давтагддаг ажилд
ихээхэн цаг зарцуулдаг.

EduLab дараах асуудлыг шийдвэрлэхэд чиглэнэ:

- Лабораторийн орчин, тоног төхөөрөмжийн хязгаарлагдмал хүртээмж.
- Байгалийн ухааны хичээлийн туршилт, дадлагын боломжийн хомсдол.
- Багшийн даалгавар шалгах болон үнэлгээ хийх ажлын ачаалал. Ялангуяа
  сурагчийн дүгнэлт **түүний хэмжилттэй нийцэж байгаа эсэхийг** тулгах нь
  их цаг шаарддаг.
- Сурагч бүрийн суралцах хэрэгцээ, ахиц дэвшлийг тогтмол үнэлэх боломжийн
  хязгаарлалт.

### Зорилтот хэрэглэгчид

| Хэрэглэгч | Юу хийж чадах вэ |
| --- | --- |
| **Сурагчид** | Цахим лаборатори ашиглан туршилт хийх, мэдлэгээ бататгах, даалгавраа шалгуулах, алдаагаа ойлгож засах |
| **Багш нар** | Даалгавар боловсруулах, шалгах, үнэлгээ өгөх, сурагчдын гүйцэтгэлийг хянах ажлаа хялбаршуулах |
| **Сургууль, боловсролын байгууллага** | Лабораторийн нөөц хязгаарлагдмал нөхцөлд сургалтын боломжоо нэмэгдүүлэх |

## 3. Үндсэн функцүүд

> Энэ хэсэгт **одоо ажиллаж байгаа** боломжуудыг жагсаав. Төлөвлөж буй
> боломжууд [7-р хэсэгт](#7-одоогоор-ажиллаж-буй-болон-цаашид-хөгжүүлэх-боломжууд) бий.

### 3.1. Цахим лаборатори (3 lab)

| Lab | Сурагч юу хийх вэ | Юуг нээх вэ |
| --- | --- | --- |
| ⚡ **Омын хууль** (физик) | Хүчдэл (U), эсэргүүцлийг (R) slider-аар өөрчилж, амперметрийн заалтыг (±2% алдаатай) хэмжинэ | `I = U/R`, график: `I` ба `U/R` |
| 🕰️ **Математик дүүжин** (физик) | Утасны урт (L), массыг (m) өөрчилж, бодит үетэйгээр хэлбэлзэх дүүжингийн 10 хэлбэлзлийг секундомероор хэмжинэ | `T ~ √L`, **масс нөлөөлдөггүй** гэдгийг (түгээмэл буруу ойлголт) |
| 🧪 **Хүчил-шүлтийн титрлэлт** (хими) | Концентраци нь тодорхойгүй HCl-ийг 0.1 М NaOH-оор титрлэнэ. «Ерөнхий» slider-аар ойртож, «Нарийн» slider-аар (1 алхам = 1 дусал) **анхны цайвар ягааныг** олно | Тодорхойгүй хүчлийн концентраци `C = C(NaOH)·V(NaOH)/V(HCl)` |

- Lab бүр **таамаглал → туршилт, хэмжилт → дүгнэлт** гэсэн бодит
  лабораторийн алхмаар явагдана.
- Хэмжилтийн хүснэгт, график бодит хугацаанд зурагдана. Титрлэлтэд pH-ийн
  муруй, фенолфталеины өнгө (өнгөгүй → цайвар ягаан → тод ягаан) харагдана.
- Аль алхам хийхийг сануулга зааж өгнө.
- Титрлэлтийн хүчлийн концентраци туршилт бүрт санамсаргүй тул хариуг
  хуулбарлах боломжгүй.

### 3.2. Хиймэл оюунд суурилсан ухаалаг багш (Gemma 4)

Сурагч илгээмэгц **Gemma 4** ажлыг үнэлгээний шалгуурын (rubric) дагуу
шалгаж:

- **шалгуур бүрийн оноо, тайлбар** (жишээ нь `Таамаглал 1/1`,
  `Эквивалент цэгт зөв зогссон 4/4`),
- нийт оноо,
- сурагчид "Та..." гэж хандсан зөвлөмжийг санал болгоно.

Багш AI-ийн саналыг **«Ашиглах»** товчоор хуулж, засаад батална. **Эцсийн
үнэлгээг үргэлж багш гаргана.**

**Яагаад энгийн текст шалгагчаас ялгаатай вэ?** Сервер lab бүрийн
хэмжилтээс **баримтуудыг өөрөө тооцоолно**, AI зөвхөн сурагчийн дүгнэлт
эдгээр баримттай нийцэж байгаа эсэхийг дүгнэнэ:

| Lab | Серверт тооцоологдох баримт |
| --- | --- |
| Омын хууль | Хэмжилт бүрийн U/R-ээс зөрөх хувь, U тогтмол байсан эсэх, R–I хамаарал |
| Дүүжин | Онолын 2π√(L/g)-ээс зөрөх хувь, хэмжилтээс гаргасан g, ижил уртад масс өөрчлөхөд T хэр өөрчлөгдсөн |
| Титрлэлт | Туршилт бүр "хүрээгүй / зөв зогссон / X мл хэтрүүлсэн", C(HCl), зөв туршилтуудын дундаж ба зөрүү |

Иймд сурагч "масс ихсэхэд дүүжин удааширсан" гэж итгэлтэй бичсэн ч
хэмжилт нь эсрэгийг харуулбал AI зөрчлийг илрүүлж тухайн шалгуурын оноог
хасна.

**Бодит Gemma 4-ээр туршсан үр дүн** (титрлэлт, 10 оноо):

| Сурагчийн ажил | AI оноо |
| --- | --- |
| 3 удаа зөв цэгт зогсож, зөв туршилтуудын дунджийг авсан | **10 / 10** |
| Хэтрүүлсэн туршилтаа дунджид оруулсан | **5 / 10** |
| мл-ийг л болгоогүй ("120 моль/л"), ганц туршилт | **0 / 10** |

### 3.3. Даалгавар удирдлагын систем

- Багш virtual lab эсвэл бичгийн даалгавар үүсгэнэ: нэр, тайлбар, rubric,
  дээд оноо, хугацаа.
- Даалгаврыг **ангид оноож** өгнө. Илгээх үед зөвхөн тухайн ангийн сурагчид
  сонгогдоно.
- Даалгавар бүрийн илгээлтийн жагсаалт: AI оноо, төлөв (хүлээгдэж буй /
  үнэлсэн), багшийн оноо.

### 3.4. Багш, сурагч, ангийн бүртгэл

- **Ангиуд:** нэр, анги түвшин, хариуцсан багш нар, сурагчийн тоо.
- **Багш нар:** erxes-ийн хэрэглэгчийг багш болгож бүртгэнэ (хичээл, утас).
- **Сурагчид:** овог нэр, анги, код, эцэг эхийн нэр ба утас, сонголтоор erxes
  Contact-тэй холбоно.

## 4. Ашигласан технологи, хамаарал

| Давхарга | Технологи |
| --- | --- |
| **AI** | Gemma 4 (`gemma-4-26b-a4b-it`) — Google AI Studio API |
| **Backend** | Node.js, TypeScript, Apollo Server (Federation subgraph), MongoDB / Mongoose, `erxes-api-shared` |
| **Frontend** | React 18, Rspack Module Federation, `erxes-ui`, `ui-modules`, Apollo Client, React Hook Form + Zod, Recharts |
| **Орчин** | erxes monorepo (Nx + pnpm), MongoDB 7 (replica set), Redis 7, Docker |

Шинэ npm хамаарал нэмээгүй. Бүгд erxes monorepo-д байгаа сангуудыг
ашигладаг.

**Техникийн гол шийдвэрүүд:**

- **AI хурд:** Gemma 4-ийн бодох горимыг `thinkingLevel: minimal` болгосноор
  нэг үнэлгээ ~30 секундээс **5–10 секунд** болсон, оноо нь өөрчлөгдөөгүй
  (хэмжиж шалгасан).
- **Найдвартай байдал:** загвар 500/429 алдаа өгвөл дараагийн Gemma 4 загвар
  руу автоматаар шилжинэ. 90 секундийн timeout, тасарсан шалгалтыг
  дахин эхлүүлэх боломжтой.
- **Шалгуурын нэр:** rubric-аас серверт тодорхой аргаар уншина, AI-д
  бичүүлэхгүй. Ингэснээр нэрс багшийн бичсэнтэй яг адилхан гарна.
- **Lab registry:** шинэ lab нэмэхэд schema өөрчлөх шаардлагагүй (хэмжилт нь
  `{ хувьсагч: тоо }` хэлбэртэй).

## 5. Суулгах болон ажиллуулах заавар

Шаардлага: Node.js 22, pnpm 9, Docker.

```bash
# 1. erxes ба энэ repo-г зэрэгцүүлэн clone хийнэ
git clone https://github.com/erxes/erxes.git
git clone https://github.com/Altntuya/erxes-hackathon.git

# 2. plugin-ийг erxes руу хуулна
./erxes-hackathon/scripts/install-into-erxes.sh ./erxes

# 3. MongoDB + Redis асаана (replica set-ийг зөвхөн анх удаа тохируулна)
cd erxes
cp ../erxes-hackathon/setup/docker-compose.local.yml .
docker compose -f docker-compose.local.yml up -d --wait
docker compose -f docker-compose.local.yml exec mongo mongosh --quiet \
  --eval 'rs.initiate({_id: "rs0", members: [{_id: 0, host: "localhost:27017"}]})'
```

`erxes/.env` файл:

```env
NODE_ENV=development
VERSION=os
MONGO_URL=mongodb://127.0.0.1:27017/erxes?replicaSet=rs0&directConnection=true
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
DOMAIN=http://localhost:3001
REACT_APP_API_URL=http://localhost:4000
GATEWAY_URL=http://localhost:4000
ENABLED_PLUGINS=edulab
JWT_TOKEN_SECRET=<openssl rand -hex 32>

# AI шалгалт (Gemma 4) — https://aistudio.google.com → Get API key
GOOGLE_AI_API_KEY=<your-key>
# Сонголттой: тодорхой загвар заах. Хоосон бол боломжтой gemma-4 загваруудыг
# дарааллаар оролдоно (gemma-4-26b-a4b-it эхэнд), нэг нь алдаа өгвөл дараагийнх руу шилжинэ
# GEMMA_MODEL=
```

```bash
# 4. Сангуудыг суулгаж ажиллуулна
pnpm install
pnpm nx build erxes-api-shared
pnpm dev:apis      # 1-р terminal
pnpm dev:uis       # 2-р terminal
```

http://localhost:3001 хаягийг нээгээд owner хэрэглэгч үүсгэнэ. Дараа нь
**EduLab** таб руу орно.

### Demo сценари

1. **Ангиуд** → "12б" анги үүсгэнэ. **Багш нар** → erxes хэрэглэгчээ "Хими"
   багшаар бүртгээд ангид ононо. **Сурагчид** → 12б-д сурагч нэмнэ.
2. **Даалгавар** → **Шинэ даалгавар**: Virtual lab, "Хүчил-шүлтийн
   титрлэлт", анги 12б, дээд оноо 10, rubric:
   ```
   Таамаглал — 1 оноо
   Дор хаяж 3 удаа давтаж, эквивалент цэгт зөв зогссон — 4 оноо
   C(HCl)-ийг зөв томьёо, нэгжээр тооцоолж, зөв туршилтуудын дунджийг авсан — 5 оноо
   ```
3. **Lab эхлүүлэх** → сурагчаа сонгож таамаглалаа бичнэ.
4. «Ерөнхий» slider-аар шар сануулга гартал, «Нарийн» slider-аар ногоон
   "Цайвар ягаан боллоо" гартал гүйлгээд **Туршилт хадгалах**. 3 удаа давтана.
5. C(HCl)-ийг тооцоолж дүгнэлтээ бичээд илгээнэ.
6. ~10–40 секундын дараа **AI оноо** гарна. Илгээлтийг нээж шалгуурын
   задаргааг хараад **Ашиглах** → **Үнэлгээ батлах**.

## 6. erxes-тэй холбогдох арга

### Техникийн интеграц (ажиллаж байгаа)

EduLab нь erxes-ийн стандарт plugin бөгөөд хоёр хэсгээс бүрдэнэ:

```
backend/plugins/edulab_api   → GraphQL subgraph (порт 3306)
frontend/plugins/edulab_ui   → Module Federation remote (порт 3012)
```

| erxes-ийн боломж | EduLab хэрхэн ашигладаг вэ |
| --- | --- |
| **Gateway, Federation** | `edulab_api` нь `startPlugin()`-ээр Redis service discovery-д бүртгүүлж, gateway (`:4000`) түүний schema-г core-ийнхтэй нэгтгэнэ |
| **Хэрэглэгч, нэвтрэлт** | Багш бүр erxes-ийн хэрэглэгч (`extend type User`, `SelectMember`), erxes-д тэр хэрэглэгчээр нэвтэрнэ |
| **Contacts** | Сурагчийг erxes Customer-тэй холбож болно (`SelectCustomer`). Илгээлт бүрт `customerId` хуулагдаж `extend type Customer`-ээр resolve хийгдэнэ |
| **Эрх** | Анги, багш, сурагч, даалгавар, илгээлт тус бүрийн Read/Manage эрхийг erxes-ийн permission системд бүртгэсэн (`src/meta/permissions.ts`) |
| **Multi-tenant** | Model бүр `generateModels(subdomain)`-ээр тухайн байгууллагын өгөгдөл дээр ажиллана |
| **UI** | `erxes-ui`, `ui-modules`-ийн компонентууд (Sheet, Form, Table, Card, Slider, Chart) тул erxes-ийн бусад хэсэгтэй адилхан харагдана |

**GraphQL API:**

| Төрөл | Нэр |
| --- | --- |
| Query | `edulabClassroomList`, `edulabTeacherList`, `edulabStudentList`, `edulabAssignmentList`, `edulabAssignmentDetail`, `edulabSubmissionList`, `edulabSubmissionDetail` |
| Mutation | `edulab{Classroom,Teacher,Student,Assignment}{Create,Update,Remove}`, `edulabSubmissionCreate`, `edulabSubmissionReview`, `edulabSubmissionAiCheck` |

### Бизнесийн интеграц (төлөвлөсөн)

EduLab-ийг erxes платформын **бизнесийн хуудсаар** дамжуулан танилцуулж,
зорилтот хэрэглэгчдэд хүргэнэ: системийн танилцуулга, үндсэн функц, ашиг
тус, хэрэглээний заавар, үйлчилгээний нөхцөлийг байршуулж, сонирхсон
сургуулиудаас хүсэлт хүлээн авна. Ялангуяа лабораторийн тоног төхөөрөмж,
байгалийн ухааны багшийн хүрэлцээ хязгаарлагдмал сургуулиудад санал
болгоно.

- [ ] Багш, сурагч, эцэг эх, удирдлагыг холбосон нэгдсэн систем
- [ ] Сургуулийн удирдлагад зориулсан тайлан, аналитик

## 8. Хүлээгдэж буй үр дүн

- Лабораторийн нөөц хязгаарлагдмал сургуулиудын туршилт, дадлага хийх
  боломж нэмэгдэнэ.
- Сурагчдын бие даан суралцах, асуудал шийдвэрлэх чадвар хөгжинө.
- Багшийн даалгавар шалгах, үнэлгээ хийхэд зарцуулах цаг багасна.
- Сурагчдын мэдлэг, чадварын ахиц дэвшлийг тогтмол хянах боломж бүрдэнэ.
- Боловсролын үйлчилгээний хүртээмж, чанарын ялгааг бууруулахад дэмжлэг
  үзүүлнэ.
- Сургуулийн сургалтын үйл ажиллагааг цахимжуулах суурь тавигдана.

## 9. Алсын хараа

**EduLab — Сурагч бүрд туршиж суралцах боломж, багш бүрд ухаалгаар ажиллах
нөхцөлийг бүрдүүлнэ.**

Бид технологийн давуу талыг боловсролын салбарт үр дүнтэй ашиглан, сурагч
бүрийн сурч хөгжих боломжийг нэмэгдүүлж, Монгол Улсын боловсролын системийг
илүү хүртээмжтэй, ухаалаг, тэгш боломжтой болгохыг зорьж байна.

## Хөгжүүлэгчдэд

### Шинэ lab нэмэх

Simulation бүр тусдаа код бөгөөд хоёр registry-д бүртгэгдэнэ:

| Хэсэг | Файл | Агуулга |
| --- | --- | --- |
| Backend | `edulab_api/src/modules/lab/<lab>.ts` → `registry.ts` | Хувьсагчид, AI-д өгөх баримтын тооцоолол (`describeFacts`) |
| Frontend | `edulab_ui/src/modules/lab/<lab>/` → `registry.ts` | Симуляцийн компонент, график, хувьсагчид |

### Синк ба шалгалт

Plugin-ийг erxes monorepo дотор хөгжүүлээд энэ repo руу синк хийнэ.

```bash
./scripts/sync-from-erxes.sh ../erxes
```

```bash
pnpm nx lint edulab_ui
pnpm nx build edulab_ui
pnpm nx build edulab_api
```

Plugin бүрийн дэлгэрэнгүй гарын авлага: `backend/plugins/edulab_api/AGENTS.md`,
`frontend/plugins/edulab_ui/AGENTS.md`.
